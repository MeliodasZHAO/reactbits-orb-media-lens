# ReactBits Orb × Media Lens Lab

An interactive Next.js/WebGL study combining a liquid AI Blob orb with a Black Hole-inspired gravity field, plus a reusable media lens for images, GIFs, and video.

The lab includes:

- Dark, Light, Graphite, and adjustable Chromatic orb treatments
- Liquid internal motion, pointer response, and edge refraction
- Circular and rounded-square media lenses
- Edge-only gravitational distortion from upper-right to lower-left
- Click ripple, media positioning, scaling, and adjustable refraction
- A bundled 960×960 MP4 demo video

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the lab.

The ReactBits registry license key is read from `.env.local` and is intentionally not committed.
